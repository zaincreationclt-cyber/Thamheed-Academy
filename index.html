🔔
പ്രധാന അറിയിപ്പുകൾ യഥാർത്ഥ അറിയിപ്പുകൾ Firebase ബന്ധിപ്പിച്ച ശേഷം ലഭ്യമാകും.

🔐 Student Login

രജിസ്റ്റർ ചെയ്ത വിവരങ്ങൾ നൽകി നിങ്ങളുടെ അക്കൗണ്ട് പരിശോധിക്കുക.

ശ്രദ്ധിക്കുക: ഈ മാതൃകാ പേജിൽ യഥാർത്ഥ ലോഗിൻ പ്രവർത്തനക്ഷമമല്ല. Firebase സുരക്ഷിതമായി ബന്ധിപ്പിക്കുന്ന അടുത്ത ഘട്ടത്തിൽ മാത്രമേ അക്കൗണ്ട് സ്ഥിരീകരിക്കൂ.

👤 Student Profile

വിദ്യാർത്ഥിയുടെ വിവരങ്ങൾ Firebase ബന്ധിപ്പിച്ച ശേഷം ഇവിടെ കാണിക്കും.

🛡️ Admin Dashboard

Admin-ന് വിദ്യാർത്ഥികൾ, പുസ്തകങ്ങൾ, നോട്ട്സ്, ടൈംടേബിൾ, അറിയിപ്പുകൾ എന്നിവ കൈകാര്യം ചെയ്യാൻ ഈ വിഭാഗം ഉപയോഗിക്കാം.

ഈ UI പൊതുവായി കാണാവുന്നതാണ്. Admin പ്രവേശനവും അനുമതികളും സുരക്ഷിതമായി Firebase വഴി നടപ്പിലാക്കുന്നതുവരെ സ്വകാര്യ ഡാറ്റയോ എഡിറ്റിംഗ് സൗകര്യങ്ങളോ ചേർക്കരുത്.
